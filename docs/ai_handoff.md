
## 2026-11-25 Lead: Museum scene scale fit and debug browser (PresentationEnvironment.unity)

- `PresentationDirector.FitModel` now fits every model to the screen using the rig camera projection matrix (the Kmax camera `fieldOfView` is not the real frustum). Tunables: `fitHeightFraction` 0.60 (clears the info panel), `fitWidthFraction` 0.85 (covers the turn). Models are placed at the `ModelPlacement` object, whose sphere is hidden at runtime.
- `debugBrowse` (default on) shows models in item-list order with Previous / Next buttons and a "index / total  title" counter (`PresentationDebugBrowser`); arrow keys work too; wraps at both ends. Console logs `[Presentation Browse]` with the applied scale. Turn off for the real show.
- Optional `ModelFloor` empty object: if present, `FloorContactShadow` lands at its Y and fades with hover height; otherwise the shadow sits at the model's lowest point.
